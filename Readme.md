# DMorse — Morse Code Decoder

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)

> Python-based Morse code encoder and decoder for signal translation and practical use.

## How to Get DMorse

### Method 1: Download and Run

1. Download the `Dmorse.py` file from the repository.
2. Run the tool:

```bash
python Dmorse.py
```

or:

```bash
python3 Dmorse.py
```

### Method 2: Copy Code Manually

1. Copy the full `Dmorse.py` code.
2. Paste it into a new file and save it as `Dmorse.py`.
3. Run it:

```bash
python Dmorse.py
```
